# Отчёт о лабораторной работе №3 по дисциплине "Введение во frontend-разработку"

### *Ход работы:*
Вариант №2, базовый, средний и повышенный уровни сложности.
Актуальная версия сайта опубликована тут: https://bithoffka.github.io/introduction_to_frontend_development/.

### *Общая структура сайта:*

| Страница | Название файла | Содержание |
| :--- | :--- | :--- |
| Главная | `index.html` | Приветствие, краткая информация об авторе, логотип университета и описание цели создания учебного проекта. |
| Обо мне | `about.html` | Подробная биография, фотография, информация об образовании и перечень профессиональных навыков. |
| Друзья | `friends.html` | Карточки друзей-одногруппников с их фотографиями, ссылками на Telegram-профили и короткая заметка о форматах общения. |
| Увлечения | `hobbies.html` | Развернутое описание интересов с нумерованным списком, тематическими фотографиями и интересным фактом. |
| Группа | `group.html` | Информация о студенческой группе ПИЖ-б-о-26-1, полный алфавитный список одногруппников, блок об активе группы с фотографиями. |
| СПС | `sps.html` | Теоретический материал для якорного партнера РТК ИТ (Высоконагруженные системы на Python), архитектурная схема взаимодействия компонентов и ссылки на официальную документацию. |

Для каждой страницы сайта была создана базовая структура HTML-документа с указанием русского языка страницы через атрибут `lang="ru"`. В секции `<head>` настроена кодировка UTF-8, добавлен метатег `viewport` для корректного масштабирования, задан заголовок вкладки браузера с помощью тега `<title>` и подключена единая внешняя таблица стилей `styles/style.css` через тег `<link>`. В файле стилей с помощью правила `@font-face` подключены локальные шрифты `Montserrat` и `Montserrat Alternates`, выполнен глобальный сброс отступов (`margin: 0; padding: 0; box-sizing: border-box;`), а в псевдоклассе `:root` объявлены CSS-переменные для единой синей цветовой палитры сайта (`--text-color`, `--bg-color`, `--bg-color-rgb`, `--dark-blue`, `--dark-blue-rgb`). Сам тег `<body>` настроен как вертикальный Flex-контейнер с минимальной высотой `100vh`, что гарантирует прижатие подвала к нижней границе экрана.

В `<body>` семантическим тегом `<header>` выделена «шапка» сайта, внутри которой размещены главный заголовок (`<h1>`), обернутый в ссылку на главную страницу, и блок навигации (`<nav>`). Шапка оформлена с помощью Flexbox (`justify-content: space-between`), ограничена по максимальной ширине (`max-width: 1500px`), центрирована и зафиксирована при прокрутке экрана с помощью свойства `position: sticky`. Навигация внутри `<nav>` содержит семантический заголовок `<h2>` (визуально скрытый через `display: none`) и маркированный список (`<ul>`) с горизонтальным расположением ссылок для перехода по основным страницам сайта и плавным эффектом прозрачности при наведении (`transition: opacity 0.3s ease`).

В нижней части каждой страницы создан единый подвал (`<footer>`), также выровненный по ширине основного контента (`max-width: 1500px`) с использованием Flexbox. Внутри подвала выделен блок `.footer-social` с заголовком `<h2>Мои контакты</h2>` и горизонтальным маркированным списком (`<ul>`), в котором текстовые ссылки заменены на векторные SVG-иконки (`phone.svg`, `email.svg`, `github.svg`, `telegram.svg`, `vk.svg`), снабженные атрибутами доступности `aria-label` и микроанимацией подъёма при наведении (`transform: translateY(-3px)`). Для всех внешних ссылок использованы защитные атрибуты `target="_blank"` и `rel="noopener noreferrer"`. Правая часть подвала выделена блоком `.footer-copyright`, где внутри абзаца (`<p>`) с тегом уменьшенного текста (`<small>`) выведена информация об авторе и копирайте.

### *Перечень использованных семантических тегов и их назначение*:

*   **header** — Шапка сайта. В проекте используется для размещения главного заголовка страницы и навигационного меню.
*   **nav** — Навигационный блок. Применяется для группировки ссылок главного меню для быстрой навигации по страницам сайта.
*   **main** — Контейнер для основного, уникального содержимого страницы (исключает повторяющиеся элементы вроде шапки и подвала).
*   **article** — Независимый, самодостаточный блок контента (например, основная статья «Обо мне», теоретический материал про «Высоконагруженные системы» или индивидуальная карточка друга).
*   **section** — Логический раздел внутри страницы или статьи (например, разделы «Биография и опыт», «Образование и достижения», «Список группы»), каждый из которых обязательно имеет собственный заголовок.
*   **aside** — Блок с дополнительной (вспомогательной) информацией «на полях», которая косвенно связана с основным контентом (список навыков, интересные факты, актив группы, ссылки на документацию).
*   **footer** — Подвал сайта. Содержит контактные данные, функциональные ссылки и информацию об авторских правах.
*   **figure и figcaption** — Контейнер для группировки визуального контента (фотографий, логотипа вуза, архитектурной схемы) и семантически связанных с ним текстовых подписей.

### *Типы гиперссылок, применённых на страницах*:

*   **Относительные ссылки** — используются для навигации между страницами внутри самого сайта (например, `href="about.html"`). Применены в главном меню навигации и в заголовке шапки.
*   **Абсолютные ссылки** — ведут на сторонние веб-ресурсы (например, Telegram, VK, GitHub, официальные сайты документации). В коде они дополнены атрибутами `target="_blank"` и `rel="noopener noreferrer"` для безопасного открытия в новых вкладках.
*   **Функциональные (ссылки-протоколы)** — используются для прямого взаимодействия с приложениями на устройстве пользователя (вызов номера телефона через `tel:` и отправка электронного письма через `mailto:`).

### *Различия по сравнению с прошлой лабораторной работой:*

1. **Подключение каскадной таблицы стилей и типографики:** Во все HTML-документы добавлено подключение единого файла стилей `styles/style.css`. С помощью директивы `@font-face` подключены локальные шрифты `Montserrat` (для основного текста) и `Montserrat Alternates` (для заголовков и акцентных элементов).
2. **Внедрение CSS-переменных и единой цветовой схемы:** В псевдоклассе `:root` заданы пользовательские переменные (`--text-color`, `--bg-color`, `--bg-color-rgb`, `--dark-blue`, `--dark-blue-rgb`), обеспечивающие строгое оформление всех страниц сайта в единой синей цветовой гамме с использованием относительных единиц измерения (`rem`).
3. **Построение сеток и компоновка на основе Flexbox:** Для `<body>`, `<header>`, `<main>`, `<footer>` и внутренних блоков контента применён модуль Flexbox. Разработана система переиспользуемых утилитарных и компонентных классов (`.container`, `.container-block`, `.container-center`, `.container-vertical`, `.container-no-wrap-space-between-stretch`, `.container-center-stretch`, `.blue-border-left`, `.line-height`), позволяющая гибко управлять расположением карточек, пропорциями колонок (`flex: 2` для `<article>` и `flex: 1` для `<aside>`), тенями и отступами.
4. **Модернизация шапки и навигации:** Шапка сайта (`<header>`) получила фиксированную при прокрутке позицию (`position: sticky`), ограничение максимальной ширины (`max-width: 1500px`) и скругление углов. Из блока `<nav>` убраны второстепенные списки локальной якорной навигации (и соответствующие якорные `id` у секций), за счет чего меню стало компактным и единообразным на всех страницах.
5. **Обновление подвала и переход на SVG-иконки:** Подвал (`<footer>`) разделён на функциональные блоки `.footer-social` и `.footer-copyright`. Текстовые ссылки на контакты и социальные сети заменены на векторные иконки в формате SVG (`phone.svg`, `email.svg`, `github.svg`, `telegram.svg`, `vk.svg`) с атрибутами доступности `aria-label` и плавной анимацией при наведении курсора.
