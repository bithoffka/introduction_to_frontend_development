>Краткое описание кода:

Создал базовую структуру HTML-документа, указав русский язык страницы через атрибут lang="ru". В секции `<head>` настроил кодировку UTF-8, добавил метатег viewport для корректного масштабирования на мобильных устройствах и задал заголовок вкладки окна браузера. В теле документа `<body>` использовал семантические теги HTML5. В шапке `<header>` разместил главный заголовок первого уровня `<h1>` с названием страницы и описание в теге `<p>`. ### *Повышенный уровень сложности:*
![Фото кода в IDE](https://github.com/bithoffka/introduction_to_frontend_development/blob/main/lab1/media/hard_var2_photo.png?raw=true)

>Краткое описание кода:

Создал базовую структуру HTML-документа, указав русский язык страницы через атрибут lang="ru". В секции `<head>` настроил кодировку UTF-8, добавил метатег viewport для корректного масштабирования на мобильных устройствах и задал заголовок вкладки окна браузера. В теле документа `<body>` применил развернутую семантическую разметку HTML5.

В шапке `<header>` разместил главный заголовок первого уровня `<h1>` с ФИО и краткую информацию в теге `<p>`. Для навигации по странице создал блок `<nav>` с заголовком `<h2>` и маркированным списком `<ul>`, в котором разместил внутристраничные (якорные) ссылки `<a>` с атрибутом `href="#id"` для быстрого перехода к нужным блокам.

Основное содержимое обернул в тег `<main>` и разделил на смысловые разделы с помощью тегов `<section>`, назначив им уникальные идентификаторы `id`. Каждому разделу задал заголовок второго уровня `<h2>`. В разделе «Обо мне» разместил фотографию с помощью контейнера `<figure>`, тега `<img>` и подписи `<figcaption>`, а в тексте добавил внешнюю ссылку `<a>` с открытием в новой вкладке (`target="_blank"`).

Для структурирования информации о навыках и достижениях использовал независимые блоки `<article>` с заголовками третьего уровня `<h3>` и абзацами `<p>`. Также на странице реализовал все виды списков: вложенный маркированный список `<ul>` (выделив заголовок тегом `<strong>`), список определений `<dl>` с терминами `<dt>` и их расшифровкой `<dd>`, а также нумерованный список `<ol>` для отображения результатов экзаменов.

Дополнительно выделил текст жизненного подхода с помощью тега блочной цитаты `<blockquote>`. Завершил страницу семантическим подвалом `<footer>`, внутри которого использовал специальный тег `<address>` для контактных данных, добавил ссылку на электронную почту через атрибут `mailto:` и разместил знак копирайта в теге абзаца `<p>`.
