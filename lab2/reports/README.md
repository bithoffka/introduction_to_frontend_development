# Отчёт о лабораторной работе №2 по дисциплине "Введение во frontend-разработку"

### *Ход работы:*
Вариант №2, базовый, средний и повышенный уровни сложности.
Актуальная версия сайта опубликована тут: https://bithoffka.github.io/introduction_to_frontend_development/.

### *Общая структура сайта:*

| Страница | Название файла | Содержание |
| :--- | :--- | :--- |
| Главная | `index.html` | Приветствие, краткая информация об авторе, логотип университета и описание цели создания учебного проекта. |
| Обо мне | `about.html` | Подробная биография, фотография, информация об образовании и перечень профессиональных навыков. |
| Друзья | `friends.html` | Карточки друзей-одногруппников с их фотографиями, ссылками на Telegram-профили и короткая заметка о форматах общения. |
| Увлечения | `hobbies.html` | Развернутое описание интересов с нумерованным списком, тематическими фотографиями и интересным фактом. |
| Группа | `group.html` | Информация о студенческой группе ПИЖ-б-о-26-1, полный алфавитный список одногруппников, блок об активе группы с фотографиями. |
| СПС | `sps.html` | Теоретический материал для якорного партнера РТК ИТ (Высоконагруженные системы на Python), архитектурная схема взаимодействия компонентов и ссылки на официальную документацию. |

Для каждой страницы сайта была создана базовая структура HTML-документа с указанием русского языка страницы через атрибут lang="ru". В секции `<head>` настроена кодировка UTF-8, добавлен метатег viewport для корректного масштабирования на мобильных устройствах и задан заголовок вкладки браузера с помощью тега `<title>`.

В `<body>` семантическим тегом `<header>` выделена «шапка» сайта, внутри которой размещены главный заголовок (`<h1>`) и блок навигации (`<nav>`). Навигация разбита на два маркированных списка (`<ul>`) с элементами и ссылками (заголовки списков выделены тегами `<h2>`): первый список отвечает за переход по страницам сайта, а второй используется для локальной якорной навигации.

В нижней части страницы создан единый подвал с контактными данными. Контакты структурированы с помощью вложенных маркированных списков, куда добавлены ссылки на телефон, почту и профили в соцсетях с помощью `<a>`. Для всех внешних ссылок использованы защитные атрибуты `target="_blank"` и `rel="noopener noreferrer"`. В самом конце добавлен абзац (`<p>`) с тегом уменьшенного текста (`<small>`) для вывода информации об авторе и копирайта.

### *Перечень использованных семантических тегов и их назначение*:

*   **header** — Шапка сайта. В проекте используется для размещения главного заголовка страницы и навигационного меню.
*   **nav** — Навигационный блок. Применяется для группировки ссылок главного меню и списка якорных ссылок для быстрой навигации по текущей странице.
*   **main** — Контейнер для основного, уникального содержимого страницы (исключает повторяющиеся элементы вроде шапки и подвала).
*   **article** — Независимый, самодостаточный блок контента (например, основная статья «Обо мне», теоретический материал про «Высоконагруженные системы» или индивидуальная карточка друга).
*   **section** — Логический раздел внутри страницы или статьи (например, разделы «Биография», «Образование», «Список группы»), каждый из которых обязательно имеет собственный заголовок.
*   **aside** — Блок с дополнительной (вспомогательной) информацией «на полях», которая косвенно связана с основным контентом (список навыков, интересные факты, актив группы, ссылки на документацию).
*   **footer** — Подвал сайта. Содержит контактные данные, функциональные ссылки и информацию об авторских правах.
*   **figure и figcaption** — Контейнер для группировки визуального контента (фотографий, логотипа вуза, архитектурной схемы) и семантически связанных с ним текстовых подписей.

### *Типы гиперссылок, применённых на страницах*:

*   **Относительные ссылки** — используются для навигации между страницами внутри самого сайта (например, href="about.html"). Применены в главном меню навигации.
*   **Якорные ссылки** — обеспечивают плавный переход к определенному логическому блоку на текущей странице (например, href="#biography" ссылается на id="biography"). Используются во втором блоке навигации под главным меню.
*   **Абсолютные ссылки** — ведут на сторонние веб-ресурсы (например, Telegram, VK, GitHub, официальные сайты документации). В коде они дополнены атрибутами target="_blank" и rel="noopener noreferrer" для безопасного открытия в новых вкладках.
*   **Функциональные (ссылки-протоколы)** — используются для прямого взаимодействия с приложениями на устройстве пользователя
